## 1. Goal and standard
A complete, self-contained, publication-grade report (UC Berkeley dissertation standard) of the thickness-dependent IWO TFT TCAD study: literature basis (every item used, page-exact), inputs, one section per parameter with its derivation (or how it could be derived), the code, every important run (including the ones that do NOT fit, used to show how each parameter controls the curves), and the final results, in a scientific flow: question -> evidence -> model -> derivation -> implementation -> calibration -> falsification tests -> mechanisms -> predictions -> validation status -> conclusions.
Each chapter: (1) an opening paragraph (motivation, what the chapter answers), (2) the body, (3) a closing `keyresult` box or short summary. Write in a precise, sober scientific voice; never exaggerate novelty or certainty. Distinguish *demonstrated*, *strongly supported*, *plausible*, *rejected*, and *calibrated* vs *validated* exactly as in `PKG/analysis_2026-09-25/SYNTHESIS.md`.

## 2. Hard rules
1. **ASCII only** in every .tex file. No Unicode (no mu, times, minus, approx, superscripts, arrows, curly quotes, en-dashes). Use LaTeX: `$\mu$`, `$\times$`, `$-$`, `$\approx$`, `$^{-3}$`, `$\rightarrow$`, ``` ``text'' ```, `--`.
2. **Units** with siunitx: `\SI{8.955e-7}{\farad\per\centi\metre\squared}`, `\SI{2.0}{nm}`, `\SI{0.7}{V}`, `\si{cm^{-3}}` also acceptable, or the macros `\cmcu`, `\cmsq`, `\cmVs`, `\Aum`, `\mVdec` inside math.
3. **Macros** are defined in `REPORT/preamble.tex` (read it). Use them (`\Vthcc`, `\muFE`, `\muband`, `\Cox`, `\dEc`, `\Nt`, `\NTA`, `\WTA`, `\Qf`, `\Qb`, `\Ndeff`, `\run{0014}`, `\file{path_with_underscores}`, `\prov{FITTED}` ...). Math macros only inside `$...$`. Do not define new global macros; if unavoidable, define with a writer prefix (e.g. `\newcommand{\dOneFoo}`) at the top of your own file.
4. **Citations: natbib, page-exact.** `\citep[p.~21539]{Lin2022}`, `\citep[pp.~5--6]{Januar2026}`, `\citep[p.~5, Fig.~3a]{Januar2026}`, `\citet[p.~502]{Si2021}`. EVERY statement taken from a paper carries the exact page. Page numbers follow section 5 (page map). Verify each page by reading the `===== PAGE N =====` block in `PKG/inputs/papers_text/<paper>.txt`. Never cite a page you have not checked.
5. **No long quotations.** Paraphrase; numbers, equations and symbol definitions may be reproduced. At most a few-word quotation, rarely.
6. **Numbers must be traceable.** Every simulated number names its run (`\run{0038}`) or file; every analysis number names the report/script it comes from (e.g. `S1 report`, `\file{analysis_2026-09-25/S1_electrostatics_6p3nm.md}`). Do not invent numbers, sources or runs. Where evidence is missing write "not determined from the available data".
7. **Apply the corrections of SYNTHESIS.md section K** (e.g. \run{0027} is malformed and retracted; $\SSmin$ is not a robust metric -- use fixed-current SS; confinement is not identified from ID-VG; ATLAS tmu = 1.5 in the elevated-temperature runs; FINAL_STATUS overclaims). Never repeat a superseded claim as if valid; where history matters, state it and its correction.
8. **Labels**: `ch:*` chapters, `sec:*` sections, `fig:<stem>` figures, `tab:*` tables, `eq:*` equations. Prefix your own non-registry labels with your chapter tag (e.g. `sec:lit-januar-stack`, `eq:d1-cox`). Use `\cref{}` / `\Cref{}` for references. You may reference ONLY (a) labels you define, (b) labels in the registries below. Every registry label assigned to you MUST be defined by you.
9. **Figures**: include only figures from the figure registry (section 7) assigned to your chapter, as `\includegraphics[width=\linewidth]{<stem>}` (the graphicspath is `figures/`; the PDF is generated by the figure agents; do not give an extension). Label = `fig:<stem>`. Write the caption from the registry description (what is plotted, runs, what to notice). You may reference figures owned by other chapters via `\cref{fig:<stem>}`. Existing PNG copies listed in the registry are included the same way.
10. **Tables**: booktabs (`\toprule \midrule \bottomrule`); long tables with `longtable`; wide tables `\small` or `\footnotesize` with `tabularx`. Escape `%`, `&`, `_`, `#` in text.
11. **Your file(s) only.** Write only the files assigned to you (plus your `REPORT/bib/extra_<TAG>.bib` for NEW bibliography keys, never redefining existing keys). Do not edit package files, do not launch ATLAS, do not modify other writers' files.
12. **Length**: be complete rather than short; typical chapter 3000-9000 words. Dense tables are welcome.

## 8. Status vocabulary (use consistently)
Evidence classes (macros): \evDATA measured curve; \evNUM converged ATLAS, model-internal; \evCAL fitted to the same curve; \evOOS out-of-sample test designed before the outcome; \evPOST designed/evaluated after the outcome; \evPRED registered, untested; \evSURR specialist surrogate; \evTHEORY; \evLIT; \evCORR. Verdicts: demonstrated / strongly supported / plausible, unverified / rejected / not determined.
