Subject: Request for measurement records and additional data, IWO TFT thickness series (2, 6.3, 13.2 nm)

Dear colleagues,

We have completed a TCAD (Silvaco ATLAS) analysis of the IWO transfer curves for the 2, 6.3 and 13.2 nm devices. The model reproduces all three curves, but it is calibrated on those same curves, so it cannot yet be called validated. Several conclusions also depend on information that the workbook does not contain. We would be grateful for the following, listed in order of importance.

1. Records for the existing curves
   - Drain voltage and current units used (we assumed VD = 0.7 V and A/um from the schematic).
   - Sweep direction, step dwell time, forward and reverse (hysteresis) sweeps if available.
   - Measurement temperature and ambient (air, vacuum, nitrogen).
   - Gate current IG and source current IS recorded with each sweep. These are needed to explain the off-state current floors, which rise about 1000 times from 2 to 13.2 nm.

2. Replicate devices
   - Transfer curves of 3 to 5 devices per thickness from the same batch. With one device per thickness we cannot tell whether the 0.29 V threshold offset of the 6.3 nm device is physical or device-to-device spread.

3. One independent measurement per thickness
   - C-V curves (quasi-static and at 2 to 3 frequencies) on the same stack for each thickness. This fixes the flat-band voltage and the trapped charge, and it is the single most useful addition.
   - ID-VD output curves at VG = 1, 1.5, 2, 2.5 and 3 V (VD from 0 to 3 V). We have registered model predictions for these.
   - Transfer curves at a second temperature. The 65 C and 85 C curves of the 2 nm device mentioned in the Supporting Information (Fig. S12) of Januar et al. (Small Structures, 2026) would already serve.

4. Film and contact information
   - Thickness measurement method and uncertainty (XRR, ellipsometry, TEM) for each film.
   - Definition of "about 2 % W" (atomic, cation or mol% WO3; target or film composition).
   - TLM or contact-resistance data for the Pd contacts, if available.
   - Optical band gap versus thickness (UV-vis or ellipsometry), if available; this directly tests the quantum-confinement assumption.

If some items are not available, please let us know, so that we can state them as limitations in the manuscript.

Thank you very much.
