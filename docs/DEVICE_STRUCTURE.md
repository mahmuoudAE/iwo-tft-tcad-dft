## Electrical representations (both generated by scripts/build_iwo_decks.py)

A. Reduced electrical deck (used for all calibration runs): IWO (regions 1+2; region 2 = 0.25 nm regularization layer for the interface sheet) / Al2O3 (region 3, eps 9.0) / HfO2 (region 4, eps 19.57); gate = Dirichlet boundary at the HfO2 bottom with the TiN work function; source/drain = Dirichlet boundaries on the IWO top surface over 0-2 um and 22-24 um; MESH WIDTH = 1 um. The n+ Si is screened by the continuous TiN and is omitted. Justification: in DC a continuous metal is an equipotential; replacing its volume by a boundary with the same work function changes neither the field in the dielectrics nor the contact boundary condition, and removes ~5k nodes (Astra kept Conductor/Palladium volumes and obtained the same class of fits).

B. Physical structure deck (`structure: full`, used for the FINAL runs 0012-0014 at the user's request): the same IWO regions; `region material=Al2O3` (2 nm) and `region material=HfO2` (15 nm) with the permittivities set explicitly (9.0 / 19.57; the ATLAS built-in defaults for these names are not the measured values); a 50 nm `Conductor` volume for the TiN gate (TiN is not in the ATLAS metal table) carrying the gate electrode, work function 4.70 eV on CONTACT; a 70 nm `Air` region above the channel; 70 nm x 2 um `Palladium` source/drain electrode volumes on the IWO top surface with no CONTACT work function (Ohmic, ASSUMED - no TLM data). Electrical equivalence with A was verified in the real solver: run_0012 (B) vs run_0008 (A), identical parameters, drain current within 0.1 % at every compared bias (docs/NUMERICAL_CONVERGENCE.md, check M).

Coordinates (um): x = 0..24 (contacts 0-2, 22-24; channel 2-22); y = -t-0.07..-t Air/Pd, -t..0 IWO, 0..0.002 Al2O3, 0.002..0.017 HfO2, 0.017..0.067 TiN gate volume (B) / gate boundary at y = 0.017 (A).

Cox = 8.955e-7 F/cm^2 (EOT 3.86 nm). Cox/q = 5.59e12 cm^-2 V^-1.
